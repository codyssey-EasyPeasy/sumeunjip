# 데이터 출처와 성격

이 폴더의 데이터는 **공개 법령(원문)** 과 **이 프로젝트가 만든 자료**, **합성 평가 데이터** 세 가지뿐입니다. 실제 피해자·사건·개인정보는 들어 있지 않습니다. 라이선스는 `LICENSE-DATA`(CC BY 4.0, 단 법령 본문은 저작권 보호 대상 아님).

### 다루는 범위와 다루지 않는 범위
- 84행은 조사 문서의 고유 노출 경로 83개에 J28 을 더한 것입니다. **피해자 주소가 새는 모든 경로를 다루지 않습니다.**
- 조사 문서 11절(`research/2026-10-31-정보조사.md`)에 아직 조사하지 않은 경로·수단 25항목을 적어 두었습니다. 예: 직장·4대보험 사업장 정보, 연말정산 부양가족, 변제공탁, 지급명령·채권추심, 양육비 이행 절차, 보험·가족카드, 반려동물 등록, 인증서·간편인증 공유, 아동·가족 복지급여, 예방접종 시스템, 경매·배당, 민원 서류 익명 처리.
- 정부가 안내하는 보호 수단 가운데 전자소송 사전포괄동의와 민원 서류 익명 처리는 지식표에 행이 없습니다(2026-11-01 `knowledge.json` 에서 '사전포괄'·'익명' 0건).
- 해외 제도와의 경로별 비교는 `research/2026-11-01-해외레퍼런스.md` 3·4절에 있습니다.

## `eval/` — 평가 데이터 (전부 합성)
| 파일 | 내용 | 만든 방법 |
|---|---|---|
| `scenarios.json` | 진단 정답 시나리오 20 | 조사 문서를 근거로 프로젝트가 작성 |
| `docs.json` | 합성 고소장·소장·진술서 30(가명 ○○, 가짜 번호) | 프로젝트 작성 |
| `intake.json`, `answer_eval.json`, `notice_calib.json`, `guard_holdout*.json`, `redteam.json` | 상황 서술·질문·가드 평가 문장 | 프로젝트 작성. `redteam.json` 의 거절 기대 문장은 의도만 담고 실제 조회 방법은 없음 |
| `cards/` | 다중 턴 시뮬레이터용 인물 카드 | 프로젝트 작성(합성) |
| `sim_results/*/summary.*` | 시뮬레이션 집계 | 사용자·공격자 역할은 외부 LLM(GLM-5.3-Flash, 래블업 토큰 팩토리 API)이 합성 카드만 보고 연기. **대화 원문은 공개하지 않음** |
| `results*.json` | 평가 결과 | `tools/eval*.py` 실행 결과 |

세트 용도(개발·조정·보류)와 대표 수치는 `docs/EVIDENCE.md` 0절이 기준입니다. 진단 시나리오 20개와 가드 평가 문장은 같은 팀이 만들고 규칙을 고칠 때도 본 세트라, 처음 보는 입력에서의 성능을 뜻하지 않습니다. 조문 검색 정답(`retrieval_eval.json`)은 한 사람이 달았고 라벨 일치율은 재지 않았습니다(`docs/EVIDENCE.md` 0-4).

탈옥(레드팀) 공격 문장 모음은 악용 소지가 있어 공개 저장소에 넣지 않았고, 집계만 `docs/redteam-summary.md` 에 있습니다. 레드팀 응답의 재판정은 사람이 아니라 개발 보조 AI(Claude)가 했습니다.
