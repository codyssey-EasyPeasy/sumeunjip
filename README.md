# 숨은집 지킴이

스토킹·가정폭력·교제폭력·성폭력 피해자가 **피신한 새 주소가 행정·소송·생활 기록을 통해 상대에게 새어 나가는 경로**를 진단하고, 경로마다 **그 경로를 막는 제도**를 근거 조문과 함께 안내하는 웹 서비스입니다. 2026 해커톤 주제 02(AI 기반 정보보호 서비스) 출품작입니다.

> **법률정보 안내이며 법률상담이 아닙니다.** 긴급하면 112, 여성긴급전화 1366(24시간), 대한법률구조공단 132로 연락하세요. 이 저장소의 모든 예시·평가 데이터는 합성 데이터이며 실존 인물·사건과 무관합니다.

## 무엇을 하나
- **노출 경로 진단**: 피해 유형(가정폭력·스토킹·교제폭력·성폭력)과 상황(이사 직후, 소송 중, 자녀 학교, 차량, 위치 공유 등 30개 항목)을 고르면, 84개 경로 중 해당하는 것을 급한 순서로 보여 줍니다. 어떤 제도를 권할지는 **규칙 엔진**이 정합니다.
- **막는 제도 안내**: 제도마다 근거 조문(시행일), 대상 피해 유형, 신청처, 서류, 한계, 확인 수준을 표시합니다. 신청하면 상대에게 통지되는 제도는 확인 체크를 거치게 합니다. 막을 제도가 없는 경로(16개)는 '잔여 위험'으로 따로 안내합니다.
- **상황 정리(AI)**: 자유롭게 적은 글에서 체크 항목 후보를 미리 골라 줍니다. 사용자가 항목을 확인·수정해야 진단합니다. 주입된 지시문·특수 토큰은 지우고, 글에 근거 낱말이 없는 항목은 버립니다.
- **근거 답변(AI)**: 고른 제도에 대한 질문에 지식표 행과 공개 조문만으로 답합니다. 생성 → 문장별 검증 → 1회 재생성 → 실패하면 원문 발췌. 통지 여부·효과 시점 질문은 생성하지 않고 지식표 원문으로 답합니다.
- **제출 서류 점검·다시 쓰기**: 고소장·소장 초안에서 주소·학교·직장·차량번호·전화 같은 위치 단서를 찾아 표시하고(1단계는 브라우저 안에서만), 원문 문장과 정렬되는 안전한 문장을 제안합니다. 새 사실이 끼면 규칙 치환으로 대신합니다.
- **사람을 찾는 방법은 다루지 않습니다.** 2단 가드로 분명한 타인 위치 찾기만 거절하고, 거절에도 내 정보를 지키는 제도 2~3개와 1366·132·112 를 붙입니다. 애매한 질문은 거절 대신 보호 안내를 붙여 답합니다. 열람·교부 절차 조문은 검색 대상에서 뺐습니다.

| 구성 | 경로 | 내용 |
|---|---|---|
| 웹 | `web/` | 바닐라 HTML/JS. 외부 CDN·쿠키·localStorage 없음, 빠른 나가기, 서류 점검 1단계(`static/detect.js`), 대화 이력은 메모리에만 |

| 추론 서버 | `gpu/` | FastAPI(:8000). bge-m3 임베딩, bge-reranker-v2-m3 재순위, GLiNER 개체명 인식, 의도 점수, `/llm/*`(intake·answer·rewrite), 공통 출력 가드·답 검증(`verify.py`), 가드 사본(`guard.py`) + vLLM Qwen3-8B-AWQ(:8001, 로컬 바인드) |
| 지식 데이터 | `data/knowledge.json`, `data/laws/` | 경로·제도 84행, 법령 조문 스냅샷 174건(국가법령정보센터 현행본, 노출 가능 131건) |
| 평가 | `data/eval/`, `tools/` | 합성 시나리오·서류·레드팀 질의, 다턴 시뮬레이터(`tools/sim/`, 카드 38장), 평가 스크립트 |
| 실행 | `scripts/`, `gpu/*.sh` | 앱·추론 서버·vLLM 시작·중지(PID 파일 + `/proc/<pid>/cmdline` 확인 뒤 종료) |
| 문서 | `docs/`, `research/`, `pt/` | 명세(`SPEC.md` §11 이 실제 동작), 아키텍처, 실증 자료 색인(`EVIDENCE.md`), 레드팀 요약, 법령 조사, 발표 자료 |

## 실행
요구: Python 3.12, [uv](https://docs.astral.sh/uv/). 추론 서버는 NVIDIA GPU(L4 23GB 에서 실측 20.6GB 사용). 서류 점검 평가에는 Node.js.

```bash
# 운영 API + 웹 (127.0.0.1:8080, 접근 로그는 메서드·경로·상태코드만)
uv sync --frozen
GPU_URL=http://<추론서버>:8000 scripts/start_app.sh     # 중지: scripts/stop_app.sh

# 추론 서버 (:8000). 모델은 $MODELS_DIR(기본 ~/models) 캐시에서 읽는다
cd gpu && uv sync && ./start.sh                         # 중지: ./stop.sh

# 내부 LLM (vLLM, 127.0.0.1:8001). vLLM 은 별도 가상환경(기본 ~/vllm-venv),
# 모델은 LLM_MODEL_PATH(기본 ~/models/Qwen3-8B-AWQ). 요청·생성 로그 끔
./llm_start.sh                                          # 중지: ./llm_stop.sh

# 시험 (GPU·모델 없이)
uv run --frozen pytest -q tests                                   # 2026-10-31: 230 passed
cd gpu && uv run --with pytest python -m pytest -q tests          # 2026-10-31: 120 passed
```
추론 서버가 없으면 근거 검색은 키워드 검색(`fallback: true`)으로, LLM 기능은 화면에서 숨겨진 채 체크박스 방식으로 동작합니다. LLM 이 실패해도 다른 LLM 으로 넘기지 않습니다.

## 한계와 남은 위험
- **자기 보호 질문 오거절 16건이 남아 있습니다**(v3 의 23건 중 `2418ad9` 로 7건 해소). 아이 학교를 옮기는 질문, 가방에서 나온 위치 추적 의심 물건, '같이 산 적 없다'는 부정 답 같은 문장입니다. 모두 보호 대안과 1366 이 붙지만 거절은 거절입니다.
- 운영 앱 경로 측정(`2418ad9`)에서 답할 수 있는 근거 질문 5개 중 1개(a4)가 3회 모두 입력 가드에 거절됐습니다(`results_app_llm.json`, 12/15).
- **보호 안내가 넓게 붙습니다.** v3 사용자 카드 40장 중 38장(응답 96건)에 붙었습니다.
- **소형 LLM 은 틀릴 수 있습니다.** 근거 답 첫 생성문의 근거 없는 문장은 3.6%(서버 판정)였고, 작업 중 출력 표본을 읽어 본 추정도 약 2~4% 였습니다(정식 집계 파일 없음, 미확인). 검증 루프가 걸러 낸 뒤의 '0'은 같은 검증기로 다시 잰 값이라 독립 판정이 아닙니다. 그래서 통지·효과 시점 질문은 생성하지 않습니다.
- **intake 단독 정확도가 낮습니다**(유형 0.575, 상황 재현율 0.276). 사용자가 체크 항목 화면에서 확인·수정해야 합니다.
- **생활권 단서(동네·단골 가게 등)는 탐지하지 못합니다**(0/11). 직장 단서 재현율도 0.5 입니다.
- 다턴 시뮬레이터는 GLM 이 사용자·공격자를 연기하므로 같은 시드라도 대화가 달라지고, 시드 1~2개라 표본이 작습니다. 레드팀 '대책 후' 값과 v3 시뮬레이션은 `fc84eb4` 배포본 기준이며 `2418ad9` 로 전체를 다시 돌리지 않았습니다.
- 법령 정보는 2026-10-31 기준 스냅샷입니다. 쉬운 말 설명 84행은 모두 사람 검수 전이고, 확인 수준은 확인 49 · 부분확인 31 · 미확인 4 입니다.
- **모든 수치는 합성 데이터에서만 나왔습니다.** 실제 이용자·실제 서류로 평가하지 않았습니다.
- 시연 배포는 TLS 없이 ssh 터널로만 접근합니다. 공개 배포 전에는 TLS·전 엔드포인트 속도 제한·운영 정책이 필요합니다.
