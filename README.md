# 숨은집 지킴이

스토킹·가정폭력·교제폭력·성폭력 피해자가 **피신한 새 주소가 행정·소송·생활 기록을 통해 상대에게 새어 나가는 경로**를 진단하고, 경로마다 **그 경로를 막는 제도**를 근거 조문과 함께 안내하는 웹 서비스입니다. 2026 해커톤 주제 02(AI 기반 정보보호 서비스) 출품작입니다.

> **법률정보 안내이며 법률상담이 아닙니다.** 긴급하면 112, 여성긴급전화 1366(24시간), 대한법률구조공단 132로 연락하세요. 이 저장소의 모든 예시·평가 데이터는 합성 데이터이며 실존 인물·사건과 무관합니다.

## 무엇을 하나
- **노출 경로 진단**: 피해 유형과 상황(이사 직후, 소송 중, 자녀 학교, 차량, 위치 공유 등 30개 항목)을 고르면, 84개 경로 중 해당하는 것을 급한 순서로 보여 줍니다.
- **막는 제도 안내**: 제도마다 근거 조문(시행일), 대상 피해 유형, 신청처, 서류, 한계, 확인 수준을 표시합니다. 신청하면 상대에게 통지되는 제도는 확인 체크를 거치게 합니다. 막을 제도가 없는 경로는 '잔여 위험'으로 따로 안내합니다.
- **제출 서류 점검**: 고소장·소장 초안에서 주소·학교·직장·차량번호 같은 위치 단서를 찾아 표시하고 안전한 문장을 제안합니다.
- **사람을 찾는 방법은 다루지 않습니다.** 열람·교부 절차 조문은 검색 대상에서 빼고, 위치 탐색 의도의 질문은 거절합니다.

## 구조
| 구성 | 경로 | 내용 |
|---|---|---|
| 웹 | `web/` | 바닐라 HTML/JS. 외부 CDN·쿠키·localStorage 없음, 빠른 나가기, 서류 점검 1단계(브라우저 안 정규식) |
| 운영 API | `app/` | FastAPI. 규칙 진단 엔진(`engine.py`), 가드(`guard.py`), 근거 검색(`retrieval.py`), 내부 LLM 프록시(`llm.py`) |
| 추론 서버 | `gpu/` | FastAPI. bge-m3 임베딩, bge-reranker-v2-m3 재순위, GLiNER 개체명 인식, 의도 분류, vLLM Qwen3-8B-AWQ(상황 정리·근거 답변·문장 다시 쓰기) |
| 지식 데이터 | `data/knowledge.json`, `data/laws/` | 경로·제도 84행, 법령 조문 스냅샷 174건(국가법령정보센터 현행본) |
| 평가 | `data/eval/`, `tools/` | 합성 시나리오·서류·레드팀 질의, 다중 턴 시뮬레이터(`tools/sim/`), 평가 스크립트 |
| 문서 | `docs/`, `research/`, `pt/` | 명세·아키텍처, 법령 조사, 레드팀 요약, 발표 자료 |

설계 원칙: 어떤 제도를 권할지는 **규칙 엔진**이 정하고, AI는 검색·재순위·단서 탐지·의도 분류·문장 보조에만 씁니다. 사용자 입력은 서버에 저장하지 않고 로그에도 남기지 않으며, 서비스 실행 중 외부 LLM을 호출하지 않습니다. 자세한 내용은 `docs/architecture.md`, `docs/SPEC.md`.

## 실행
요구: Python 3.12, [uv](https://docs.astral.sh/uv/). 추론 서버는 NVIDIA GPU(24GB 권장).

```bash
# 운영 API + 웹 (127.0.0.1:8080)
uv sync --frozen
GPU_URL=http://<추론서버>:8000 uv run uvicorn app.main:app --host 127.0.0.1 --port 8080

# 추론 서버 (:8000), vLLM (:8001)
cd gpu && uv sync && ./start.sh && ./llm_start.sh

# 시험
uv run --frozen pytest -q tests
```
추론 서버가 없으면 근거 검색은 키워드 검색으로, LLM 기능은 화면에서 숨겨진 채로 동작합니다.
