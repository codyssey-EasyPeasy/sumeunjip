# 시연 영상 녹화 (tools/demo)

제출용 시연 영상을 **실제로 동작하는 서비스 화면**에서 자동으로 녹화합니다. 앱 코드가 아니며 `web/` 는 건드리지 않습니다.

> **녹화 조건 충족(2026-11-01 04:14 KST):** 프런트엔드 개편(PR #2)이 main 에 병합됐고, 운영 서버에 앱·웹 `993db4f` 가 배포됐습니다(GPU 서버는 `642e5e1` 그대로). 아래 (1)로 녹화합니다.
> **대회 서버는 2026-11-01 13:00 에 삭제됩니다.** 그 뒤에는 실제 AI 화면을 녹화할 수 없고, 로컬 모의 서버(아래)로 흐름만 볼 수 있습니다.

## 공식 가이드 요약 (지켜야 할 것)
| 항목 | 규칙 | 이 도구에서 |
|---|---|---|
| 형식 | MP4 | webm 녹화 → H.264 · yuv420p · 30fps · faststart MP4 로 변환 |
| 내용 | 실제 서비스 화면 녹화. 슬라이드·디자인만 있는 영상은 인정 안 됨 | 운영 서버 화면을 Playwright Chromium 으로 조작·녹화 |
| 길이 | 2분 이하(처음 2분만 평가) | 전체 상한 118초, 넘으면 실패 처리. 변환도 120초에서 자름 |
| 해상도 | 1080p 권장 | 1920x1080 (화면 125% 확대) |
| 범위 | 핵심 기능을 입력부터 출력까지 | 아래 9단계(샷 리스트는 「2분 영상 샷 리스트와 자막」) |
| 편집·자막·내레이션 | 선택 | 화면 아래 단계 캡션 띠(녹화 때만 덧씌움, 앱에는 없음) |

## 파일
| 파일 | 내용 |
|---|---|
| `record_demo.mjs` | 녹화기. `--check` 는 선택자 확인만, 기본은 녹화 + 변환 + 검증 |
| `scenario.json` | 단계(캡션·단계별 최대 시간·머무는 시간), 합성 입력, **선택자 지도** |
| `package.json` | `playwright-core` 1.63.0 고정(브라우저는 chromium-1243) |

녹화 단계(약 100~115초 목표)
1. 첫 화면 — 들어올 때마다 뜨는 안전 안내 팝업, 위쪽 긴급 연락처 띠(112·1366·132), 오른쪽 위 ‘빠른 나가기’ 강조 → 팝업 ‘닫기’
2. 말로 설명하기 — 합성 자유서술 입력 → 항목 골라 보기 (`/api/intake`)
3. 자동 체크 확인 — 상황 묶음(‘우편·통신’)을 펼쳐 빠진 항목(옛 주소로 우편물)을 직접 체크 → ‘고른 항목을 확인했습니다’. AI 가 고른 항목이 있는 묶음은 자동으로 열립니다
4. 진단 결과 — ‘지금 먼저 할 일’, 카드는 ‘생길 수 있는 위험’ → ‘받을 수 있는 도움’ 순, 통지 경고 확인 체크 → 신청 방법 펼침 (`/api/diagnose`)
5. ‘이게 무슨 뜻인가요?’ — 우편물 카드에 질문, 답과 배지 (`/api/answer`)
6. 서류 점검 — 합성 진술서 붙여 넣기 → 기본 점검 → 정밀 점검 (`/api/doccheck`)
7. 안전한 문장으로 바꾸기 (`/api/rewrite`)
8. 위치 탐색 질문 거절 + 보호 대안 — 근거 조문 탭 (`/api/search`). **질문 입력칸은 흐리게 가림**(`docs/PT_HANDOFF.md` 시연 원칙: 다른 사람을 찾는 질문은 화면에 그대로 보이지 않게). 끄려면 `inputs.maskLocateInput=false`
9. 빠른 나가기 — Esc 두 번 → 구글 ‘날씨’ 검색 화면

입력은 모두 `scenario.json` 의 **합성 문장**입니다(실존 인물·주소 없음, 이름·지명은 ○○). 답을 기다릴 때는 고정 sleep 이 아니라 해당 API 응답과 화면 변화를 기다리고, 단계마다 `maxSec` 을 넘기면 실패합니다.

## 2분 영상 샷 리스트와 자막 (1차 심사용, 2026-11-01 확정)

영상 한 편이 덱 2쪽의 흐름을 한 사람의 합성 사례(가정폭력·막 이사함·상대가 먼저 소송·자녀 전학·옛 주소 우편)로 따라갑니다. 자막은 `scenario.json` 의 `steps[].caption` 이고, **메시지는 '해킹이 아니라 서류로 샌다 → 결정은 규칙·사람 → AI 문장은 검증 → 이 도구 자신은 새 유출 경로가 되지 않는다'** 입니다. 슬라이드만 나오는 장면은 넣지 않습니다(가이드상 실제 동작 화면만 인정).

| # | 단계 id | 목표 구간 | 화면 | 자막 |
|---|---|---|---|---|
| 1 | `intro` | 0:00–0:08 | 시작 화면, 안전 안내 팝업 → 닫기 | 피해자의 새 주소는 해킹이 아니라 서류로 샙니다 — 84개 유출 경로를 먼저 점검하는 피해자 본인용 정보보호 도구 (입력은 모두 합성) |
| 2 | `intake` | 0:08–0:20 | 말로 적기 → AI 가 항목을 미리 고름 | 말로 적으면 우리 GPU 위의 LLM(Qwen3-8B)이 해당 상황을 미리 고릅니다 — 외부 AI 로 보내지 않습니다 |
| 3 | `confirm` | 0:20–0:28 | 묶음 펼쳐 직접 체크 → '확인했습니다' | AI 가 고른 항목은 본인이 확인해야 제출됩니다 — 결정은 사람이 합니다 |
| 4 | `diagnose` | 0:28–0:58 | '지금 먼저 할 일' → **통지 경고 → 체크 → 신청 방법 열림** | 권할 제도는 규칙 엔진이 정합니다(84행, 같은 입력엔 같은 결과) — 상대에게 통지되는 제도는 그 위험을 확인해야 신청 방법이 열립니다 |
| 5 | `ask` | 0:58–1:16 | 근거 답 + 답 종류 배지 | 답은 문장마다 근거 조문을 확인합니다 — 실패하면 1회 다시 만들고, 그래도 안 되면 원문 발췌로 대신합니다 |
| 6 | `doccheck` | 1:16–1:24 | 단서 색칠(기본 → 정밀) | 서류 점검 — 1단계는 이 브라우저 안에서만, 2단계 정밀 점검(GLiNER + 규칙)은 누를 때만 우리 서버로 |
| 7 | `rewrite` | 1:24–1:32 | 바꾼 문장 제안 | 위치 단서를 지운 문장 제안 — 원문에 없던 숫자·이름·장소가 나오면 모델 출력을 버리고 규칙으로 가립니다 |
| 8 | `locate` | 1:32–1:44 | 찾기 질문 거절(**입력칸 흐림**) + 보호 대안 | 다른 사람의 위치를 찾는 질문은 두 번 판정해 거절하고, 내 정보를 지키는 제도를 안내합니다 (질문 입력칸은 가림) |
| 9 | `exit` | 1:44–1:57 | Esc 두 번 → 날씨 검색 | Esc 두 번이면 화면이 지워지고 날씨 검색으로 — 입력은 저장하지 않습니다 · github.com/codyssey-EasyPeasy/sumeunjip |

- 목표 구간은 계획값입니다. 실제 길이는 `report-record-*.json` 의 단계별 시간으로 확인하고, 전체 118초 상한과 단계별 `maxSec` 은 그대로입니다(자막만 바꿨고 단계 id·시간 키·선택자는 바꾸지 않음).
- **자막을 바꿨으므로(2026-11-01 07시대) 그 전에 찍은 MP4 에는 옛 자막이 들어 있습니다.** 제출본은 이 자막으로 다시 찍은 실서버 녹화여야 합니다. 10-31 23시대 로컬 리허설본(모의 응답·스텁 나가기)은 제출용이 아닙니다.
- 전략안의 **고정 배지**("실서버 · 커밋 993db4f · 외부 AI 호출 0 · 입력은 합성")와 **마지막 5초 저장소 화면**은 녹화기에 없습니다(넣으려면 `record_demo.mjs` 수정이 필요해 이번 범위 밖). 그래서 '합성'은 1단계 자막에, 저장소 주소는 9단계 자막에 넣었습니다.
- 대기 구간을 편집으로 배속하면 그 구간 자막 끝에 '(대기 2배속)'처럼 표시합니다. 자동 녹화본은 배속하지 않습니다.
- 자막에는 숫자를 84(지식표 행 수)와 모델 이름 외에 넣지 않습니다. 성능 수치는 덱 5쪽과 `docs/EVIDENCE.md` 0절이 기준입니다.

  설치 권한이 없으면 NanumGothic 을 넣은 fontconfig 파일을 만들어 `export FONTCONFIG_FILE=<fonts.conf 경로>` 로 지정합니다.

## (1) 프런트 병합·배포 뒤 실제 녹화
```bash
# 0) 노트북 VPN(NCP SSL-VPN) 연결 상태에서, 운영 서버 화면으로 터널을 연다(따로 터미널, 녹화 끝날 때까지 유지)
ssh -N -L 18080:127.0.0.1:8080 hk-ops
#    로컬 18080 이 이미 쓰이고 있으면(ss -ltn | grep 18080) 다른 포트로: -L 18088:127.0.0.1:8080 → 아래 --base 도 18088

# 1) 서버 상태: llm 이 true 여야 2·5·7단계 칸이 보인다
curl -s http://127.0.0.1:18080/api/features          # {"llm":true}

cd tools/demo
export FONTCONFIG_FILE=<fonts.conf 경로>     # 한글 글꼴이 설치돼 있으면 생략

# 2) 선택자 확인(녹화 없음, 빠른 나가기 이동은 스텁). "missing": [] 와 "ok": true 여야 한다
node record_demo.mjs --check --base http://127.0.0.1:18080

# 3) 리허설 녹화(구글 대신 스텁) — 길이·화면을 먼저 본다
node record_demo.mjs --base http://127.0.0.1:18080 --stub-exit

# 4) 실제 녹화(빠른 나가기가 진짜 구글 날씨 검색으로 이동)
node record_demo.mjs --base http://127.0.0.1:18080
```
- 출력: 녹화기 기본 출력 폴더(`record_demo.mjs` 의 `DEFAULT_OUT`)에 `sumeunjip-demo-<시각>.mp4` (+ 원본 `.webm`, `report-record-<시각>.json`). 원하는 곳에 두려면 `--out <폴더>` 를 붙입니다. **영상은 저장소에 커밋하지 않습니다.**
- 끝나면 표준 출력 JSON 의 `probe` 를 봅니다. 녹화기가 이미 검사하고, 어긋나면 종료 코드 2 입니다.
  기대값: `codec h264 · pixFmt yuv420p · 1920x1080 · fps 30 · faststart true · durationSec ≤ 120`.
- ffprobe 대신 같은 ffmpeg 로 직접 확인:
  ```bash
  FF=$(uv run --no-project --with imageio-ffmpeg python -c 'import imageio_ffmpeg; print(imageio_ffmpeg.get_ffmpeg_exe())')
  "$FF" -hide_banner -i <영상>.mp4 2>&1 | grep -E 'Duration|Video:'
  # 장면 훑어보기(4초마다 한 장, 4x8 격자)
  "$FF" -loglevel error -y -i <영상>.mp4 -vf "fps=1/4,scale=480:-1,tile=4x8" -frames:v 1 sheet.png
  ```
- 길이 조절: 모든 머무는 시간(`dwellMs`)에 배수를 곱하는 `--pace` 를 씁니다. 리허설이 100초보다 짧으면 `--pace 1.2`, 115초보다 길면 `--pace 0.85`. 단계별로는 `scenario.json` 의 `dwellMs`.
  - 참고(2026-10-31 로컬 모의 서버 실측): `--pace 1` 로 87.4초(`report-record-*.json` 의 `totalSec`). 모의 응답은 거의 즉시라서, 운영 서버(말로 설명하기 약 2초, 무슨 뜻 답 5~8초, `docs/evidence/sample-conversation.md`)에서는 10~20초 늘어날 것으로 봅니다(**미확인**, 배포 뒤 3번 리허설로 확인).
- 실제 녹화의 9단계에서 구글이 동의·로봇 확인 화면을 띄우면 그 화면이 찍힙니다. 다시 녹화하거나 (2) 수동 녹화로 마지막 장면만 대체합니다. `--stub-exit` 로 찍은 영상은 마지막 화면에 ‘리허설 스텁’이 보이므로 제출용이 아닙니다.
- 실패 시: 표준 오류의 `[demo] step <id> FAILED: ...` 를 봅니다. `selector not found: <키>` 면 아래 ‘화면이 바뀌었을 때’.

## 화면이 바뀌었을 때 (프런트 개편 대응)
- `scenario.json` 의 `selectors` 는 키마다 후보 목록입니다. 앞에서부터 시도해서 처음 보이는 요소를 씁니다.
  - 문자열: Playwright 선택자(`#id`, `.class`, `text=...`)
  - 객체: `{"role":"button","name":"/빠른 나가기/"}`, `{"label":"..."}`, `{"placeholder":"..."}`, `{"text":"..."}` — `/.../` 는 정규식
- `--check` 기록(선택자 키 전부 찾음, 9단계 모두 통과, `"missing": []`):

  | 대상 | 화면 | 결과 | 걸린 시간(`totalSec`) | 시각(KST) |
  |---|---|---|---|---|
  | 운영 서버 배포본(앱·웹 `993db4f`, GPU `642e5e1`), ssh 터널 | PR #2 화면(안전 안내 팝업) | 9/9 통과 | 70.3초 | 2026-11-01 04:15 |
  | 로컬 모의 서버(`993db4f`) | 같음 | 9/9 통과 | 50.1초 | 2026-11-01 03:59 |
  | 로컬 모의 서버(main `6b4b620`, `feature/frontend` `34edc21`) | 개편 전·후 | 통과 | — | 2026-10-31 |

  `--check` 시간은 선택자 확인용 실행 시간이라 녹화 길이와 다릅니다.
- 개편 뒤 `--check` 결과의 `"selectors"` 에서 `MISSING` 인 키(괄호 안이 단계)만 고칩니다. `not reached` 는 앞 단계가 실패해 확인하지 못한 키입니다. 키 이름은 바꾸지 말고 후보만 앞에 추가합니다.
- 1단계는 안전 안내 팝업의 ‘닫기’(`#safety-toggle`)를 누릅니다. 팝업 바깥 어두운 배경을 눌러도 닫히고, 다시 보려면 위쪽 띠의 ‘안전 안내 다시 보기’를 누릅니다. 옛 화면(펼쳐진 상자의 ‘안내 접기’)도 `safetyClose` 후보에 남겨 두었습니다. 둘 다 없으면 건너뜁니다.
- **리허설 영상으로 눈으로 확인할 것(미실측):** ① 팝업이 열린 동안 어두운 배경이 위쪽 긴급 연락처 띠까지 덮는지(1단계 캡션이 띠를 가리키므로, 덮이면 ‘닫기’ 뒤에 띠를 다시 강조), ② 화면 아래 고정 도움 줄(1366·132·112)이 캡션 띠와 겹치는지.

## (2) 수동 녹화 (자동 녹화가 안 될 때)
공통 준비
- 화면 해상도 1920x1080, 브라우저 **시크릿 창**을 최대화, 확대 125%. 알림은 끕니다(Windows ‘방해 금지’).
- 입력은 위 ‘녹화 단계’ 순서대로, `scenario.json` 의 `inputs` 문장을 메모장에서 복사해 붙여 넣습니다. 실제 이름·주소·연락처를 쓰지 않습니다.
- 1단계에서 안전 안내 팝업을 2~3초 보여 준 뒤 ‘닫기’를 누릅니다.
- 8단계 위치 탐색 질문은 입력칸이 보이지 않게(창 일부만 찍거나 편집에서 가림) 합니다.
- 2분 안에 끝나도록 한 번 연습한 뒤 녹화합니다.

Windows Xbox Game Bar
1. 설정 → 게임 → 캡처: ‘녹화 프레임 속도’ 30fps, ‘비디오 품질’ 높음, 오디오 녹음 끔.
2. 브라우저 창을 클릭해 활성화한 뒤 `Win + Alt + R` 로 시작/중지(창 하나만 찍힘). 결과는 `동영상\캡처` 폴더의 MP4(H.264).

OBS Studio
1. 설정 → 비디오: 기본·출력 해상도 1920x1080, FPS 30.
2. 설정 → 출력(고급) → 녹화: 형식 mp4(또는 mkv 로 찍고 ‘파일 → 다시 다중화’로 mp4), 인코더 x264 또는 NVENC H.264, 비트레이트 8000~12000 Kbps.
3. 소스에 ‘윈도우 캡처’(브라우저 창) 또는 ‘디스플레이 캡처’ → ‘녹화 시작’.

수동 녹화본 손질(앞뒤 자르기·2분 제한·규격 맞추기)
```bash
"$FF" -y -ss <시작초> -i in.mp4 -t 118 -vf "fps=30,scale=1920:1080:force_original_aspect_ratio=decrease,pad=1920:1080:(ow-iw)/2:(oh-ih)/2,format=yuv420p" \
  -c:v libx264 -preset slow -crf 18 -movflags +faststart -an out.mp4
```
