# 숨은집 지킴이 안전성·UX 개선 결과

기준: `main`의 `993db4f`와 `Daeung-03/safety-ux-improvements`의 변경 비교. 아래 수치는 **합성 입력·로컬 CPU 규칙 경로**의 결과다. 실제 피해자 데이터나 GPU 모델 전체 성능으로 해석하지 않는다.

## 구현 내용과 검증

| 항목 | 확인된 문제와 변경 | 파일 | 검증 |
|---|---|---|---|
| 생활권 단서 | 이름만 나온 장소는 제외하고, 개인의 거주지·학교·직장 관계 또는 반복 이동·방문과 결합한 시설명을 표시한다. `생활권` span에 `risk_type`, `reason`을 덧붙였다. 기본 점검과 정밀 점검의 운영 API에서 동일한 취지의 경량 규칙을 적용한다. | `web/static/detect.js`, `app/location.py`, `app/main.py` | 신규 합성 7유형, 기존 `docs.json` 30건, API 응답 테스트 |

| 장애 대응 | 정밀 점검을 누를 때 기본 규칙 결과를 먼저 만들고 GPU 오류에도 유지한다. 진단 중 중복 제출을 막고, API 실패 시 기존 결과와 입력을 보존한다. 정밀 점검 중 중복 요청도 막는다. | `web/static/app.js` | GPU 연결 실패 브라우저 스모크, API 회귀 테스트 |

`/api/doccheck`의 기존 필드 `available`, `offset_unit`, `spans`는 유지한다. 생활권 span에만 선택 필드 `risk_type: "routine_location"`과 `reason`이 추가된다. GPU 실패 시의 기존 `available: false` 응답 형태는 유지하며, 브라우저가 로컬 기본 점검을 보여 준다. 기관에 입력 글을 자동 전송하거나 신청을 접수하는 기능은 없다.

기관 링크 확인(2026-11-01 KST): `https://www.klac.or.kr/`은 HTTP 200·제목 ‘대한법률구조공단’, `https://www.kcva.or.kr/`은 HTTP 200·제목 ‘전국범죄피해자지원연합회’였다. 경찰·1366은 기존 서비스의 긴급 전화 연결을 사용한다. 외부 링크는 새 탭·`noopener noreferrer`로 열고 페이지의 `no-referrer` 정책을 유지한다.

## 개선 전후 평가

`uv run --frozen python tools/eval.py --no-gpu --out /tmp/sumeunjip-after.json`으로 기존 합성 서류 30건을 같은 1단계 브라우저 규칙으로 평가했다. strict label overlap 지표는 예측 span의 **라벨과 범위가 정답 span과 겹칠 때** 맞음으로 센다.

| 기본 점검 지표 | 이전 | 변경 후 |
|---|---:|---:|
| 생활권 정답 span 검출 | 0/11 | 10/11 |
| 전체 span 정밀도 | 0.9697 | 0.9767 |
| 전체 span 재현율 | 0.5263 | 0.7018 |
| 전체 span F1 | 0.6823 | 0.8167 |
| 진단 필수 제도·다른 유형 오적용 | 56/56 · 0건 | 56/56 · 0건 |

Guard는 `tools/benchmark_safety.py`가 기준 커밋과 현재 규칙을 같은 입력에 적용해 집계했다. 여기서 ASR은 공격 요청 중 차단·재서술 요구 없이 통과한 비율, FPR은 정상 요청 중 거절·재서술 요구 비율이다. **응답 생성의 실제 공격 성공률이 아니라 규칙 판정 통과율**이다.

| 규칙 입력 집합 | 이전 | 변경 후 |
|---|---:|---:|
| 신규 공격 4건 ASR | 2/4 (50%) | 0/4 (0%) |
| 신규 정상 4건 FPR | 1/4 (25%) | 0/4 (0%) |
| 기존 holdout 공격 20건 ASR / 정상 30건 FPR | 0/20 · 0/30 | 0/20 · 0/30 |
| 기존 redteam 공격 25건 ASR / 정상 15건 FPR | 0/25 · 0/15 | 0/25 · 0/15 |

처리 시간은 같은 로컬 프로세스·합성 입력에서 **각 입력을 최소 30회** 반복해 p50/p95를 잰 한 번의 실행 결과다. 단위 ms. 짧은 함수의 수치 차이는 실행 잡음에 민감하며 GPU 추론 시간을 포함하지 않는다.

| CPU 경로 | 이전 p50 / p95 | 변경 후 p50 / p95 |
|---|---:|---:|
| Guard `assess` | 0.1520 / 0.3524 | 0.1518 / 0.2983 |
| 브라우저 기본 단서 점검 | 0.0030 / 0.0065 | 0.0035 / 0.0063 |
| 진단 API `TestClient` | 1.5939 / 2.0698 | 1.5972 / 2.0489 |

## 실행한 검증

- 앱 전체: `uv run --frozen pytest -q tests` — 기준 572 passed·36 xfailed, 변경 후 595 passed·36 xfailed.
- GPU 코드의 모델 대역 테스트: `PYTHONPATH=gpu uv run --frozen --with numpy python -m pytest -q gpu/tests` — 187 passed·1 skipped·4 xfailed. 실제 GPU 추론은 수행하지 않았다.
- `node --check web/static/app.js`, `node --check web/static/detect.js`, `uv run --frozen python -m compileall -q app` — 통과.
- 실제 브라우저(Whale, 로컬 FastAPI): 메인 페이지, 진단 결과, 기관 연결, 112·1366, 기본 생활권 표시, GPU 연결 실패 시 정밀 점검의 기본 결과 유지, 빠른 나가기 직후 민감 화면 제거를 확인했다. 모바일 화면과 Esc 단축키는 이번 브라우저 스모크에서 직접 확인하지 않았다.

## 남은 기술적 한계

- 생활권 규칙은 명시적인 개인 문맥과 시설명에 의존한다. 이름 없는 시설, 문장을 가로지르는 복합 위치 추론, 간접 표현은 놓칠 수 있고 새로운 법률 서술에서는 오탐할 수 있다. 1단계 평가의 11건은 작은 합성 표본이다.
- LLM 기반 법률 답변의 사실성은 별도 독립 검수로 보장되지 않는다. 통지·효과 시점은 기존처럼 생성 없이 원문을 보여 준다.
- 실제 피해자 문서와 사용성 데이터가 없으며, 개인정보가 포함된 실자료로 이번 변경을 검증하지 않았다.
- GPU 동시 처리·GLiNER 추론 성능과 장애 복구 시간은 이번 로컬 CPU 시험으로 알 수 없다.
- 법령 스냅샷은 자동으로 최신화되지 않는다. 기관 링크·연락처의 유효성도 운영 중 다시 확인해야 한다.
- 기존 기록 시험에 남은 GPU 이상 응답 스키마·긴 rewrite 시간 초과 등은 변경 범위와 회귀 위험을 고려해 이번 작업에서 수정하지 않았다(`docs/TEST_RESULTS.md`).

## 향후 발전 방향 (이번 구현에는 포함되지 않음)

공공기관 공식 API와 신청 절차 연계, 개인화된 피해자 보호 Action Plan, 법률 전문가의 설명·법령 검수 체계, 법령 자동 갱신, 실제 피해자 지원기관과의 사용성 검증, 민감정보 보호 및 접근성 강화를 순서대로 검토한다. 신청이나 민감정보 전송은 이용자가 목적과 수신처를 확인한 뒤 선택할 수 있어야 한다.
