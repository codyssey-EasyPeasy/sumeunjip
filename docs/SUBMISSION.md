## ⓐ 문제 정의 및 목표 사용자 (1쪽)

### 해결하려는 문제
**피해자가 피신해도, 새 주소가 행정·소송·생활 기록을 타고 가해자에게 새어 나갑니다.**

| 사례·수치 | 내용 | 출처 |
|---|---|---|
| 2026년 9월 광주 | 스마트워치·접근금지를 받은 피해자가 이혼 소장으로 피신 주소가 드러난 뒤 살해됨. 소송 단계 주소 비공개 신청은 하지 않은 상태 | 경인일보 보도, `research/2026-10-31-정보조사.md` 5절 [2차] |
| 2026년 10월 대구 | 스토킹 잠정조치 결정문의 가해자 주소란에 피해자 새 주소가 잘못 적혀 가해자에게 전달됨 | 경북매일 보도(2026-10-28), 같은 절 [2차] |
| 스토킹 신고 | 2024년 3만 1,947건 → 2025년 4만 4,687건 | 헤럴드경제(2026-05-17) 보도, 같은 절. 원자료 미확인 |
| 교제폭력 신고 | 2024년 8만 8,394건 → 2025년 10만 5,327건 | 같은 보도. 원자료 미확인 |
| 주민등록 열람제한 신청 | 연 3,000여 건 (같은 기간 가정폭력 상담 18만~20만 건) | 서울신문(2020·2018) 보도. 원자료 미확인 |

**왜 막지 못하는가 — 구조적 원인 세 가지** (자체 법령 조사, `research/2026-10-31-정보조사.md` 1절)
1. **신청주의**: 막는 제도는 있지만 신청해야만 작동합니다. 소송 단계 주소 비공개(민사소송법 제163조 제2항)는 법원에 미리 안내할 의무가 없습니다.
2. **피해 유형별 공백**: 주민등록·가족관계 교부 제한, 피해자보호명령은 가정폭력 피해자 전용입니다. 비가족 스토킹·교제폭력에는 없고, '교제폭력'은 법률상 정의가 없습니다.
3. **역노출**: 제한을 신청하면 그 사실이 가해자에게 통지되는 제도가 있습니다(주민등록법 제29조 제7항 후단 등). 순서와 시점이 중요합니다.

| 조사 결과 | 값 | 출처 |
|---|---|---|
| 주소가 드러날 수 있는 기록·절차 경로 | **84개** (6개 영역) | `data/knowledge.json` |
| 그중 막는 제도가 **없는** 경로 | **16개** (+ 시행 예정 1개, 2027-04-22) | 같은 파일 `status` |
| 법령 원문으로 확인한 행 | 확인 49 · 부분확인 31 · 미확인 4 | 같은 파일 `confidence` |
| 신청 시 상대에게 통지될 수 있는 행 | 12개 | 같은 파일 `notify_warning` |

### 문제를 겪는 대상 (목표 사용자)
| 구분 | 누구 | 처한 상황 |
|---|---|---|
| **1차 사용자** | 스토킹·가정폭력·교제폭력·성폭력 **피해자 본인** | 막 이사했거나 소송 중. 법률 비전문가. 상대와 기기를 같이 쓰거나 감시당할 수 있음 |
| 2차 사용자 | 피해자의 **가족·지인** | 대신 찾아봐 주는 사람. 같은 안전 수칙 필요 |
| 다루지 않는 사람 | 다른 사람의 주소·위치를 **찾으려는** 사람 | 2단 가드로 거절하고 보호 제도만 안내 |

- 처음 기획은 상담사용 도구였으나, 피해자 본인이 직접 쓰도록 바꿨습니다(커밋 `a9028c5`, `docs/SPEC.md` §7). 회원가입·로그인이 없습니다.
- 피해자가 겪는 어려움: 제도가 여러 기관(주민센터·법원·학교·차량등록·우체국 등)에 흩어져 있음 → 무엇을 먼저 해야 하는지 모름 → 신청이 오히려 노출을 부를 수 있음.

## ⓑ 해결 방안 및 주요 기능 (2~3쪽)

### 서비스 개요
> 이름·주소 없이 상황만 고르거나 말로 적으면, **새 주소가 샐 수 있는 경로**와 **그 경로를 막는 제도**를 근거 조문·신청처·서류·통지 경고와 함께 **급한 순서**로 보여 주는 웹 서비스. 제출할 서류 초안 속 위치 단서도 찾아 줍니다.

**지키는 원칙** (`docs/architecture.md`, `docs/SPEC.md` §11)
- **막는 방법만** 안내합니다. 사람을 찾는 방법·조회 요건은 다루지 않고, 열람·교부 절차 조문은 검색 대상에서 뺐습니다.
- **입력을 저장하지 않습니다.** DB 가 없고, 로그에는 '메서드 경로 상태코드'만 남습니다. 표지 문자열 60회 전송 뒤 세 로그에서 0건(`docs/evidence/infra.md` §6).
- **서비스 실행 중 외부 LLM·외부 API 를 부르지 않습니다.** LLM 은 GPU 서버에 직접 띄운 Qwen3-8B 하나뿐입니다(`docs/SPEC.md` §11.7).
- **어떤 제도를 권할지는 AI 가 아니라 규칙 엔진이 정합니다.** AI 가 고른 항목은 사용자가 확인해야 제출됩니다.
- 법률정보 안내이며 법률상담이 아닙니다. 모든 결과에 112 · 1366(24시간) · 132 를 붙입니다.

### 이용 흐름
1. **안전 확인** — 긴급 연락처, 시크릿 창 권장, 빠른 나가기 위치 안내
2. **상황 입력** — 피해 유형 + 상황 체크, 또는 말로 적기 → AI 미리 선택 → 본인 확인
3. **진단 결과** — 급한 순서 체크리스트, 통지 경고 확인, 잔여 위험 대비, 결과 인쇄
4. **서류 점검** — 제출 전 초안의 위치 단서 표시와 대체 문구

**합성 예시(실제 사례 아님)**: 가정폭력으로 최근 이사, 상대가 먼저 이혼 소송을 냄, 초등학생 자녀 → '최근 이사'·'가해자가 먼저 소송을 냄'·'자녀가 학교에 다님' 체크 → '소송관계인 개인정보 보호조치(주소 등 비공개)'가 급한 정도 1로 표시(`data/knowledge.json` J1) → 통지 경고 확인 → 답변서 초안의 주소·학교를 '[주소 비공개]'로 바꿈 → 결과를 인쇄해 1366 상담에 가져감 → 빠른 나가기. (`docs/OVERVIEW.md` 6절)

## ⓒ 활용 AI 기술 및 직접 개발 범위 (4~5쪽)

### 활용한 AI 기술 (서비스 실행 중 쓰는 것)
| 모델 | 제공처(그대로 사용) | 적용 기능 | 적용 방식(우리가 만든 부분) |
|---|---|---|---|
| **BAAI/bge-m3** | HuggingFace, MIT | 근거 조문 검색, 가드의 의도 점수 | 조문 131건 임베딩 → 상위 30 후보. 가드는 자체 작성한 '찾기 의도' 시드 문장과의 max-sim 점수를 **신호 하나로만** 사용(점수 > 0.16 + 타인 지시어 + 본인 보호 맥락 없음일 때만 거절 근거, > 0.02 면 '애매함'). 임곗값은 보류 세트 `guard_holdout2.json` 으로만 정함 |
| **BAAI/bge-reranker-v2-m3** | HuggingFace, Apache-2.0 | 검색 재순위, 답 문장 근거 확인 | 후보 30 → 상위 5. 답 검증 때 문장마다 근거 조각 3개를 찾아 점수 < 0.01 이면 '근거 없음' |
| **urchade/gliner_multi-v2.1** | HuggingFace, Apache-2.0 | 서류 정밀 점검(2단계) | 자체 라벨 매핑 + 700자 조각 나눔·병합 + 정규식 결합. 1단계는 브라우저 규칙(`web/static/detect.js`) |
| **Qwen/Qwen3-8B-AWQ** (vLLM 서빙) | HuggingFace, Apache-2.0 | 상황 정리, 근거 답, 문장 다시 쓰기, 답 검증기 | thinking 끔, **JSON 스키마 강제 출력**(guided decoding), 온도 0~0.2. 프롬프트·전처리·후처리·검증 루프는 모두 자체 작성 |

**런타임에 부르는 외부 AI API: 없음.** LLM 이 실패해도 다른 LLM 으로 넘기지 않고 체크박스 방식으로 계속합니다(`docs/SPEC.md` §11.7). 모델 파일은 설치 때 HuggingFace 에서 받고, 실행 중에는 `HF_HUB_OFFLINE=1` 로 허브 접속을 끊었습니다(커밋 `6672867`).

### 실제 적용 가능성
- **이미 배포·실측된 구성**입니다. GPU 1장(L4)에 모델 4종이 올라가고(20,480MiB/23,034MiB), 진단은 CPU 에서 0.005초입니다(`docs/evidence/infra.md`).
- **GPU 가 없어도 핵심은 돕니다.** 진단은 규칙 엔진, 검색은 BM25 로 대체, LLM 기능은 숨긴 채 체크박스 방식으로 계속(`README.md`). 저비용 배포 선택지가 있습니다.
- 비용: 현재 구성을 NCP 공공기관용 정가로 셈하면 약 140만 원/월, 그중 GPU 서버 83%(`docs/COST_LATENCY.md` 1절, 작성 시점 값).
- 법적 경계를 설계에 반영했습니다: 무료·일반 법률정보 안내(변호사법 제109조 검토), AI 문장에 'AI 생성' 표시(인공지능기본법 제31조), 입력 비저장·위치 권한 요청 없음(`research/…` 7절).

### 공개 전에 반드시 할 일 (남은 위험, 숨기지 않음)
- TLS, 모든 기능의 속도 제한, 인증·운영 정책(시연은 ssh 터널 전용).
- **GPU 서버 8000 포트가 SSL-VPN 사용자에게 열려 있고 인증이 없음** → 운영 서버만 허용하도록 좁히기(`infra-2026-10-31-night.md` 7절, 미적용).
- 자기 보호 질문 오거절 18건/14대화 줄이기, 생활권 단서 탐지(0/11)·직장 단서(재현율 0.5) 보강.
- 쉬운 말 설명 84건 **사람(법률 지식 보유자) 검수**, 미확인 4행 확인.
- 시연 전 시험에서 나온 실패 항목 수정(`docs/TEST_RESULTS.md`).
