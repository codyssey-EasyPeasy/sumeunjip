# 「왜 이 프로젝트가 필요했나」 차트용 수치 데이터

- 작성일: 2026-11-01
- 내부 입력: `data/knowledge.json` (`version` "2026-10-31", 84행, sha256 앞 16자 `431c4a10a38c7d7f`)
- 외부 수치: 2026-11-01 에 원문 URL 을 다시 열어 문장을 대조한 것만 실었습니다. 교차검증에서 고친 값(FIX)은 고친 값으로 실었습니다.
- 이 문서는 데이터 정리용입니다. 시각화는 이 표를 그대로 옮겨 만들면 됩니다.

---

## 1. 목적과 원칙

1. **실제로 존재하는 수치만 씁니다.** 모든 수치에 값·단위·분모·기준일·출처를 붙였습니다.
2. **추정을 사실처럼 쓰지 않습니다.** 원문에 없고 직접 나눈 값은 모두 「계산값」으로 표시했습니다. 원문이 「추산」이라고 한 값은 「추정치」로 표시했습니다.
3. **「경로별로 몇 % 위험한가」는 만들 수 없습니다.** 84개 경로 각각의 노출 발생률이나 피해 확률은 국내외 어떤 공개 통계에도 없습니다(이번 조사 범위 기준). 이 문서는 그 대신 측정할 수 있는 대리 지표를 씁니다.
   - 막을 제도가 없는 경로 수
   - 막으려고 신청하면 가해자에게 통지될 수 있는 경로 수
   - 되돌릴 수 없는 시점(긴급도 1)의 경로 수
   - 경로별로 보도된 실제 노출 사건
4. **1차/2차 구분**
   - 1차: 정부·기관 원문
   - 2차: 언론 보도. 언론이 정부 자료를 인용했으면 「2차(○○ 자료 인용)」로 적었습니다.
   - 내부 지식표 집계는 「내부 1차」입니다. 이 프로젝트가 만든 지식표를 센 값이지, 외부 통계가 아닙니다.
5. 지식표 `basis[].primary` 는 「그 행의 1차 근거 조문」이라는 뜻입니다. 출처의 1차·2차 구분과는 다른 개념입니다.

### E. 피해 유형별로 쓸 수 있는 차단 제도 — 공백 드러내기, 내부 1차

- **제목 제안:** 스토킹·교제폭력·성폭력 피해자에겐 행정 영역 전용 제도가 없다
- **메시지:** 행정 영역(주민등록 등)의 유형 전용 제도는 가정폭력 피해자에게만 6개 있고, 다른 세 유형에는 0개입니다.
- **차트 유형:** 묶은 막대(유형별 「전용 행」 vs 「any 포함 적용 행 중 제도 있음」)
- **정의:**
  - 전용 행: `victim_types` 에 그 유형이 적힌 행
  - any 포함 적용 행: 그 유형 또는 `any` 가 적힌 행
  - 모든 유형에 적용되는 행(`["any"]` 만): 55행

| 피해 유형 (필드 값) | 전용 행 | any 포함 적용 행 | 그중 막을 제도 있음 | 행정 영역 전용 행 |
|---|---|---|---|---|
| 가정폭력 (`family`) | 25 | 80 | 64 | 6 |
| 스토킹 (`stalking`) | 11 | 66 | 50 | 0 |

- 「이 유형엔 제도 없음」을 화면에서 숨기지 않는지 점검한 결과: 6/6 (`docs/EVIDENCE.md` 62행)

- **주의:** 한 행이 여러 유형에 적힐 수 있어 전용 행 합계(51)는 행 수와 같지 않습니다. 유형 간 합산 차트(누적)는 쓰지 마십시오.

## 5. 재현 — 내부 집계 스크립트

저장소 루트에서 실행합니다. `data/knowledge.json` 을 읽기만 하고 아무 파일도 고치지 않습니다. 아래 스크립트를 저장소 밖 임시 위치에 붙여 넣지 말고, 표준 입력으로 바로 넘기면 됩니다.

```bash
cd <저장소 루트>
python3 -I - <<'PY'
import json, hashlib, collections as C
raw = open("data/knowledge.json", "rb").read()
d = json.loads(raw); I = d["items"]
AREAS = list(dict.fromkeys(i["area"] for i in I))
STATUS = ["in_force", "pending", "none"]
TYPES = ["family", "stalking", "dating", "sexual"]
cnt = lambda it: dict(C.Counter(it))
ids = lambda p: [i["id"] for i in I if p(i)]
notify = lambda i: isinstance(i["notify_warning"], str) and i["notify_warning"].strip() != ""
o = {"source": {"version": d.get("version"), "sha256_16": hashlib.sha256(raw).hexdigest()[:16], "rows": len(I)}}
o["status"] = {s: len(ids(lambda i, s=s: i["status"] == s)) for s in STATUS}
o["status_ids"] = {s: ids(lambda i, s=s: i["status"] == s) for s in ("pending", "none")}
o["area_total"] = {a: len(ids(lambda i, a=a: i["area"] == a)) for a in AREAS}
o["area_x_status"] = {a: {s: len(ids(lambda i, a=a, s=s: i["area"] == a and i["status"] == s)) for s in STATUS} for a in AREAS}
o["notify_warning"] = {"rows": len(ids(notify)), "ids": ids(notify),
    "by_area": {a: len(ids(lambda i, a=a: notify(i) and i["area"] == a)) for a in AREAS},
    "by_status": cnt(i["status"] for i in I if notify(i))}
o["none_or_notify"] = {"rows": len(ids(lambda i: i["status"] == "none" or notify(i))),
    "overlap": ids(lambda i: i["status"] == "none" and notify(i))}
o["urgency"] = {u: len(ids(lambda i, u=u: i["urgency"] == u)) for u in (1, 2, 3)}
o["urgency_x_status"] = {u: {s: len(ids(lambda i, u=u, s=s: i["urgency"] == u and i["status"] == s)) for s in STATUS} for u in (1, 2, 3)}
o["urgency1_none_ids"] = ids(lambda i: i["urgency"] == 1 and i["status"] == "none")
o["confidence"] = cnt(i["confidence"] for i in I)
o["confidence_x_status"] = {s: cnt(i["confidence"] for i in I if i["status"] == s) for s in STATUS}
o["plain_reviewed"] = cnt(str(i["plain_reviewed"]) for i in I)
vt = {}
for t in TYPES:
    spec = lambda i, t=t: t in i["victim_types"]
    appl = lambda i, t=t: t in i["victim_types"] or "any" in i["victim_types"]
    vt[t] = {"type_specific": len(ids(spec)),
             "type_specific_by_area_with_measure": {a: len(ids(lambda i, a=a: spec(i) and i["area"] == a and i["status"] != "none")) for a in AREAS},
             "applicable_incl_any": len(ids(appl)),
             "applicable_incl_any_with_measure": len(ids(lambda i: appl(i) and i["status"] != "none"))}
o["victim_type"] = vt
o["victim_type_any_only_rows"] = len(ids(lambda i: i["victim_types"] == ["any"]))
o["none_rows_all_any"] = all(i["victim_types"] == ["any"] for i in I if i["status"] == "none")
L = [b["law"] for i in I for b in i["basis"]]
o["basis"] = {"rows_with_basis": len(ids(lambda i: len(i["basis"]) > 0)), "entries": len(L),
    "primary_true": sum(b.get("primary") is True for i in I for b in i["basis"]),
    "distinct_laws": len(set(L)), "top_laws": C.Counter(L).most_common(5)}
o["pending_effective"] = {i["id"]: i["pending_effective"] for i in I if i["pending_effective"]}
o["no_trigger_rows"] = len(ids(lambda i: not (i["triggers"]["all"] or i["triggers"]["any"])))
o["flags"] = {"count": len(d["flags"]), "by_group": cnt(f["group"] for f in d["flags"])}
o["text_proxy"] = {"limits_재량": ids(lambda i: "재량" in (i.get("limits") or "")),
    "any_field_[2차]": ids(lambda i: "[2차]" in json.dumps(i, ensure_ascii=False))}
print(json.dumps(o, ensure_ascii=False, indent=1))
PY
```

- 2026-11-01 실행 결과(rc=0)가 이 문서 B~E, H-1 의 모든 내부 수치와 같습니다. 입력 sha256 앞 16자 `431c4a10a38c7d7f` 가 다르면 지식표가 바뀐 것이므로 수치를 다시 옮겨 적으십시오.
- 영역별 비율(43.5%, 62.5% 등), C+D 합계 30(35.7%), 확인 수준 비율, H-2 의 1차 비중 44.4% 는 위 출력에서 나눈 계산값입니다.
- `docs/EVIDENCE.md` 64행에도 상태·확인 수준을 세는 한 줄 명령이 있습니다.
