## 이 발췌에서 보이는 것

- 확인 질문은 1번만 했고, 위치(주소·학교·시설)를 되묻지 않았다. 자동 선택이 틀린 항목(주민등록지 같음)은 사용자가 체크 화면에서 직접 뺐다 — 자동 선택은 미리 체크일 뿐이다.
- 후속 답 4개 중 3개는 근거 id 가 붙은 AI 답, 1개는 AI 를 쓰지 않은 원문 발췌였다.

## 이 발췌에서 보이는 문제 (숨기지 않고 적는다)

- **원문 발췌 답에 같은 문장이 두 번씩 나온다.** 6번 응답 원문에는 A1 통지 경고 두 문장과 A8 고지 문장이 각각 두 번 반복돼 있다(위 인용에서는 `…` 로 줄였다). 여러 카드의 같은 통지 경고를 이어 붙일 때 중복을 거르지 않는 것으로 보인다(원인 **미확인**).
- **5번 답의 마지막 문장은 근거와 어긋날 수 있다.** A2(재량 거부)에 대해 "제한 사유가 가해자에게 서면으로 통지된다"고 했는데, 서면 통지 조항(제29조 제7·8항 후단)은 A1(열람·교부 제한)에 붙은 경고다. 문장별 검증기를 통과했지만 사람 판정은 하지 않았다(**미확인**).
- **정상 질문에도 보호 안내가 자주 붙는다.** 3·5번은 자기 보호 질문인데 등급이 `ambiguous` 로 나와 보호 안내가 붙었다. 거절은 아니지만, v3 시뮬레이션 전체에서 보호 안내가 붙은 응답은 96건/38카드다(`summary.md`).
