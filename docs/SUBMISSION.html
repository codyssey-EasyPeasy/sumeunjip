#기능하는 일판단 주체
1노출 경로 진단피해 유형 4개 + 상황 항목 30개(묶음별 접힘, AI 가 고른 묶음은 펼침) → 84개 경로 중 해당하는 것을 급한 순서로. '지금 먼저 할 일' 최대 5건결정적 규칙(의도적: 틀리면 위험한 판단은 AI 배제)
2막는 제도 안내카드마다 위험 → 도움을 먼저, 근거 조문(시행일)·신청처·서류·한계·확인 수준은 접어 둠. 통지되는 제도는 확인 체크 뒤에만 신청 방법 표시. 막을 제도 없는 경로는 '잔여 위험'결정적 규칙(같은 입력 → 같은 결과)
3말로 설명하기자유 서술(2,000자 이하) → 체크 항목 미리 선택. 주입 지시문 제거, 글에 근거 낱말이 없는 항목은 버림자체 호스팅 LLM 제안 → 본인이 확정
4근거 답고른 제도에 대한 질문에 지식표·공개 조문만으로 답. 생성 → 문장별 검증 → 1회 재생성 → 원문 발췌. 통지·시점 질문은 원문으로LLM 설명 + 문장별 근거 검증 통과분만
5서류 점검·다시 쓰기주소·학교·직장·차량·전화 단서 표시(1단계는 브라우저 안에서만), 원문과 정렬되는 안전한 문장 제안, 새 사실이 끼면 규칙 치환규칙 + GLiNER + LLM
