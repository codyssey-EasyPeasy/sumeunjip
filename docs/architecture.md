# 숨은집 지킴이 아키텍처 (초안 2026-10-31)

근거 조사: `../research/2026-10-31-정보조사.md`. 발표 자료: `../pt/index.html`.

## 원칙
1. 사용자는 피해자 본인(2026-10-31 오너 결정으로 상담원 경유 제거). 인증 없이 쓰되, 안전한 기기 안내·빠른 나가기·기록 비저장으로 보완하고 1366·132 연결을 결과마다 붙인다.
2. 출력은 막는 제도만. 사람을 찾는 방법·조회 요건·순서는 다루지 않는다.
3. 사례 정보(상황 체크값·서류 원문·결과)는 기관 경계 밖으로 나가지 않고 저장하지 않는다.
4. 결정(어떤 제도를 권할지)은 규칙 엔진이 한다. AI는 검색·재순위·서류 단서 탐지·의도 분류에만 쓴다.
5. 외부 LLM(DeepSeek)은 빌드 시점에 공개 조문 → 쉬운 말 초안, 합성 데이터 생성에만 쓴다. 상담 중 호출 0.

## 구성
| 구성 요소 | 위치 | 역할 |
|---|---|---|
| 사용자 웹 클라이언트 | 브라우저 | 피해 유형·상황 체크(이름·주소 없음), 결과 표시·인쇄, 서류 점검 1단계(정규식·사전), 빠른 나가기, 저장 안 함 |
| 웹/API + 진단 엔진 | 운영 서버 10.1.1.33 | 지식표 83행 × 피해 유형 × 상황 조건 평가, 우선순위(되돌릴 수 없는 시점 먼저), 이중용도 가드, 내용 없는 감사 로그 |
| 지식 저장소 | 운영 서버(읽기 전용) | 경로·제도·근거(법령명·조항·시행일·lsiSeq)·대상(가/스/교)·신청처·서류·한계·통지 경고·확인도·미시행 표시·검수된 쉬운 말 설명 |
| 추론 서비스 | GPU 서버 10.1.2.33 (L4 24GB) | 임베딩(bge-m3), 재순위(reranker), 서류 점검 2단계 NER, 질의 의도 분류 |
| 빌드 파이프라인 | 경계 밖(공개 정보만) | 국가법령정보센터 현행 조문 스냅샷 → 조문 단위 분할 → 임베딩 → LLM 설명 초안 → 사람 검수 → 읽기 전용 배포 |

## 평가(합성 데이터)
진단 재현율, 대상 오적용 건수(목표 0), 서류 단서 정밀도·재현율, 가드 거절률, 근거 조문 원문 일치율.

- 결정서·고지문에 새 주소가 적히는지(J10) 등 조사 문서 10절의 22건.
