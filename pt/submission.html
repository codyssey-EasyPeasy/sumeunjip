실제 적용 가능성

  • 이미 배포·실측 — L4 1장에 모델 4종, 배포 해시 = 저장소
  • GPU 없이도 핵심 동작 — 규칙 진단 + BM25 + 체크박스 방식
  • 비용(추정) — NCP 공공기관 정가 약 140만 원/월, GPU 83% (COST_LATENCY.md, 작성 시점)

공개 전 반드시 할 일 (숨기지 않음)

  • TLS · 속도 제한 · 인증 (지금은 ssh 터널 시연)
  • GPU 8000 포트가 SSL-VPN 사용자에게 열려 있고 인증 없음 → 좁히기
  • 자기 보호 질문 오거절 18건/14대화, 생활권 단서 0/11
  • 쉬운 말 설명 84건 전문가 검수, 시험 실패 항목 수정
